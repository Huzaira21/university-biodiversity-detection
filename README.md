# University Biodiversity Detection

An AI-based approach to analyze and identify biodiversity 
within the university environment.
Developed as part of Artificial Intelligence course at 
Namal University, Mianwali.

## Overview
This project uses AI and machine learning techniques 
to detect and classify biodiversity (plants, animals, 
species) within a university campus environment.

## Files
- `biodiversity.ipynb` — Complete code and analysis
- `research-paper.pdf` — Research paper
- `project-details.pdf` — Project documentation

## How to Run
1. Install Jupyter Notebook:
pip install jupyter
2. Open the notebook:
jupyter notebook biodiversity.ipynb
